# C_Lib-Embedded
1. C lib for Linked List, Queues, Stack Push and Pop ,Reg Operations and Light weight Printf (Supports Float also stm32)

NOTE: 
LW PRINTF_FLOAT (in STM32 Microcontroller Environment where uart should replace with the required uart Handler)
1. Light Weight PRINT_FLOAT used to log float data types upto 4 decimal places 
2. If we use std lib for float will take 12 KB to 13 KB of memeory this PRINT_FLOAT func will take 2KB to 3KB stack size
